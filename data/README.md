# Data Directory

Raw DREAMT data must not be committed to GitHub. Keep real dataset files local
and ensure that any use of the data follows the dataset access terms and privacy
requirements.

Expected local layout:

```text
data/
  raw/
    S002_whole_df.csv
    ...
  interim/
    participant_summary.csv
```

Use `data/raw/` for local copies of real DREAMT participant CSV files. Use
`data/interim/` for generated intermediate inventory summaries. These locations
are ignored by Git so raw data and derived local data products remain local.

## Participant Summary

`data/interim/participant_summary.csv` is generated by the Stage 1 dataset
inventory workflow. It contains one row per participant file and documents:

- participant ID and file path
- row and column counts
- available columns
- expected DREAMT schema checks
- missing wearable signal columns
- approximate recording duration from `TIMESTAMP`
- detected label column and sleep-stage value counts
- missing-value counts and percentages by wearable signal
- basic min/mean/std/max by wearable signal
- value summaries for `Obstructive_Apnea`, `Central_Apnea`, `Hypopnea`, and
  `Multiple_Events`
- any file-level read errors encountered during inventory

Fields that are naturally nested, such as value counts and per-signal
statistics, are stored as JSON strings in the CSV.

## Regenerating The Summary

From the notebook:

1. Place local DREAMT files under `data/raw/`.
2. Open `notebooks/01_dataset_overview.ipynb`.
3. Run the notebook cells that list participant files and build or load the
   participant summary.

From Python at the repo root:

```python
from src.data import summarize_dataset

summary = summarize_dataset("data/raw", output_path="data/interim/participant_summary.csv")
```

## Assumptions

- Participant files are expected to use names like `S002_whole_df.csv`.
- The default participant file glob is `S*_whole_df.csv`.
- Participant IDs are parsed from filenames with a regex and returned in a form
  like `S002`.
- The expected primary time column is `TIMESTAMP`.
- The expected primary sleep-stage label column is `Sleep_Stage`.
- If `Sleep_Stage` is absent, label-column detection falls back to conservative
  case-insensitive matching for terms such as `stage`, `label`, `sleep`,
  `annotation`, or `psg`. Multiple matches are reported as candidates rather
  than silently choosing one.
- The expected wearable signal columns are `BVP`, `ACC_X`, `ACC_Y`, `ACC_Z`,
  `TEMP`, `EDA`, `HR`, and `IBI`.
- `HR` and `IBI` are derived from `BVP`; they are summarized during inventory
  but no modeling or feature engineering is performed in this stage.
- Event annotation columns are documented during inventory only:
  `Obstructive_Apnea`, `Central_Apnea`, `Hypopnea`, and `Multiple_Events`.
